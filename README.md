# 🐷 AI 스마트 가계부 & 자산 플래너 (AI Budget Planner)

Google Gemini 3.5 Flash Lite 인공지능 기반의 맞춤형 예산 설계 및 스마트 소비 분석 웹 애플리케이션입니다.

---

## ✨ 주요 기능 및 특징

1. **보안 4자리 PIN 잠금 (Security Lock)**
   - 초기 접근 시 4자리 비밀번호(`0412`) 인증으로 개인 재정 정보를 안전하게 보호합니다.
   - 상단 `🔒 잠금` 버튼으로 언제든지 재잠금할 수 있습니다.

2. **지하철/카페 모드 (👁️ 금액 마스킹)**
   - 공공장소나 대중교통 이용 시 `👁️ 금액 숨김` 버튼을 누르면 모든 금액이 `₩ ••••••` 및 마스킹 처리되어 프라이버시를 지켜줍니다.

3. **기본 재정 설계 및 AI 예산 플래너 (Step 1)**
   - 고정 수입, 부수입, 목표 저축액, 필수 고정지출과 소비 성향(짠테크형, 밸런스형, 라이프스타일형)을 분석합니다.
   - **Google Gemini 3.5 Flash Lite**가 6대 핵심 카테고리별(식비, 주거/통신, 쇼핑/여가 등) 권장 예산과 일일 권장 지출액을 제시합니다.

4. **주요 고정지출 결제일 관리 & 캘린더 꼬리표 (Custom Fixed Expenses)**
   - 월세, 구독료, 공과금, 헬스장 등 고정지출 항목명과 결제일을 직접 등록하고 관리할 수 있습니다.
   - `➕ 고정지출 추가` 및 `✕` 삭제 지원, 스마트 캘린더 해당 일자에 보라색 꼬리표가 자동으로 표시됩니다.

5. **스마트 가계부 캘린더 & 무지출 데이 (Zero Spend Day)**
   - **무지출 스탬프**: 지출이 없는 날에는 달력에 귀여운 돼지 도장(🐷)이 콕 찍혀 절약 동기를 부여합니다.
   - **신호등 지출 뱃지**: 일일 권장 예산 이내면 초록색 안전 뱃지, 초과 시 경고 빨간색 뱃지가 표시됩니다.
   - **날짜 클릭 상세 팝업**: 달력의 특정 날짜를 클릭하면 해당 일자의 상세 지출 내역 모달이 열립니다.

6. **"커피 몇 잔 아꼈을까?" 지출 체감 변환기**
   - 현재까지 쓴 지출을 스타벅스 아메리카노(4,500원), 치킨(20,000원), 영화 관람권(15,000원) 개수로 환산하여 과소비를 체감할 수 있도록 시각화합니다.

7. **간편 플로팅 미니 계산기 (Calculator)**
   - 사칙연산과 백분율(%) 계산이 가능한 간편 계산기가 내장되어 있습니다.
   - `📥 지출 금액에 넣기` 버튼 클릭 한 번으로 계산 결과를 지출 입력란에 자동 반영합니다.

8. **데이터 영구 보존 & 초기화 (LocalStorage)**
   - 작성한 예산 및 지출 내역, 고정지출 결제일이 브라우저 로컬 저장소에 실시간 자동 저장됩니다.
   - 상단 `💾 저장` 및 `🔄 초기화` 버튼 제공.

9. **AI 지출 피드백 & 월말 회고 (Step 3)**
   - 현재까지의 소비 패턴을 분석하여 과소비 카테고리 경고 및 다음 달 절약 행동 가이드를 제공합니다.
   - 리포트 클립보드 복사 및 마크다운(`.md`) 파일 다운로드 지원.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Backend**: Python 3.10+, Flask
- **AI Engine**: Google GenAI SDK (`google-genai`), `gemini-3.5-flash-lite`
- **Frontend**: Modern HTML5, CSS3 (CSS Custom Properties & Flex/Grid), Vanilla JavaScript (ES6+)
- **Libraries**: Marked.js (Markdown Rendering)

## 🚀 실행 방법 (Getting Started)

### 1. 가상환경 활성화 및 패키지 설치
```powershell
cd C:\AI-study\ai-budget-planner
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. 환경 변수(.env) 설정
`.env` 파일에 발급받은 Gemini API 키를 입력합니다:
```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=5000
```

### 3. 애플리케이션 실행
```powershell
py app.py
```

### 4. 웹 브라우저 접속
- 주소: `http://127.0.0.1:5000`
- 기본 비밀번호: `0412`
